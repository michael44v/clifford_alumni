Using the **attached PRD** as the main source of truth, refine and correct the existing **Clifford University Alumni Association website**.

Keep the existing functionality and structure where appropriate, but apply all the following corrections and improvements:

### 1. Hero Section and School Image

* Replace the faint/background image currently used in the hero section with the **uploaded Clifford University school photo**.
* Use the uploaded school photo prominently and professionally.
* Keep the hero section clean, modern, and visually balanced.

### 2. Alumni Logo and Brand Colors

* Replace the current logo with the **newly uploaded Clifford University Alumni Association logo**.
* Use the **Alumni logo, not the Clifford University institutional logo**, throughout the website.
* Update the website's primary and secondary colors to match the colors used in the new Alumni logo.
* Maintain good contrast, readability, and a professional university-alumni appearance.

### 3. Modern Classic UI

* Maintain a **modern classic, professional, elegant, and institutional design**.
* Use consistent and visually pleasing corner radii on buttons, cards, input fields, images, containers, menus, and other shapes.
* Keep the design clean and not overly rounded.
* Use consistent spacing, typography, borders, shadows, and component styles throughout the website.
* Keep animations subtle and purposeful.
* Ensure the website remains lightweight and fast, especially on mobile devices and slow internet connections.

### 4. Alumni Registration and Verification

The existing verification/security approach should remain a major feature.

Registration must be strictly controlled so that **having access to the website link alone does not allow anyone to register as an alumnus**.

* Use the **matriculation number as the primary verification requirement**.
* A matriculation number must exist in the official alumni directory before an applicant can continue with alumni registration.
* If the matriculation number is not found in the directory, the applicant should not be allowed to register as a regular alumnus.
* Provide a separate registration pathway for **Associate Members**, who do not require an alumni matriculation number.
* Clearly distinguish between Alumni Members and Associate Members.
* Include appropriate email/phone verification and other security checks specified in the PRD.
* Prevent duplicate registrations using the same matriculation number.
* Protect members' personal information and allow members to control what information is publicly visible.

### 5. Graduation Sets and Years

Correct the graduation-set structure and make it accurate.

* The **All Sets** list should begin from the **Alpha graduating class**.
* Graduation years should currently cover **2016 to 2026**.
* The system should be structured so that when a new graduating class is added in the future, the new set and year can be added without redesigning the website.
* Do not incorrectly show previous years for a particular graduating set.
* Each graduating set must have its **accurate corresponding graduation year**.
* Example: if the Alpha Graduating Set is 2020, display it strictly as **Alpha Graduating Set - 2020** and do not associate Alpha with earlier years.
* Make the set/year structure easy for administrators to update.

### 6. Location

Improve the location system.

* Include **all 36 states of Nigeria plus the Federal Capital Territory (FCT)**.
* Cities should be organised under their respective states.
* Replace the term **"Overseas"** with **"Diaspora"**.
* Include locations outside Nigeria under Diaspora.
* The system should allow alumni to select international countries/cities where applicable.
* Location search and filtering should work across Nigeria and the Diaspora.

### 7. Faculties

Keep the faculty list strictly aligned with the **existing faculties of Clifford University**.

* Do not invent or add unsupported faculties.
* Include an **"OTHERS"** option for future faculties or academic structures that may be introduced.
* Make the faculty list manageable from the admin dashboard so new faculties can be added in the future.

### 8. Alumni Gallery

Expand the Gallery functionality.

The gallery should support:

* Individual photos of graduated alumni.
* Graduation-class/set photographs.
* Alumni reunions.
* AGM and association events.
* University memories.
* Historical photographs and archives.
* Other approved alumni activities.

Allow administrators to organise photographs by **graduating set, year, event, and category** where appropriate.

### 9. Business and Services Directory
